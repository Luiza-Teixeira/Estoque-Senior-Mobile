# Estrutura dos slides (10 slides)

1. **Capa** — Estoque Sênior Mobile · nomes e RAs · disciplina.
2. **O problema** — pequenos comércios com donos idosos ou pouco acostumados com tecnologia.
3. **A solução** — app de estoque e vendas simples e acessível; prints do Início nos dois modos.
4. **Acessibilidade** — letras grandes, “A A A”, alto contraste, botões com texto, Modo Simplificado.
5. **Tecnologias** — React Native, Expo, Expo Router, Zustand, Axios, TanStack Query, React Native Paper.
6. **Arquitetura** — desenho: telas → hooks → services → API Express; organização por features.
7. **Divisão da equipe** — 4 módulos (um por integrante) + parte da fundação de cada um.
8. **Funcionalidades** — CRUD de produtos, entradas, vendas, histórico, painel; 2 relacionamentos (Venda → Produto, Entrada → Produto).
9. **Integração com a API** — `.env` com `EXPO_PUBLIC_API_URL`, Axios único e TanStack Query.
10. **Demonstração / encerramento** — QR code do APK ou link do repositório; agradecimento.

Visual: mesma paleta do app (azul-marinho #0A2A5C, azul #0B3B8C, fundo #F5F8FC), prints reais do celular, pouco texto por slide.
