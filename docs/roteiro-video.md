# Roteiro do vídeo (até 4 minutos)

Gravar a tela do celular (Android: gravador de tela nativo) com voz por cima. Cerca de **1 minuto por integrante**.

| Tempo | Quem | O que mostrar | Fala (resumo) |
| --- | --- | --- | --- |
| 0:00–0:20 | José | Tela de login e Início | “O Estoque Sênior é um app de estoque e vendas pensado para pessoas idosas. Somos Dandália, Victoria, Jader e José.” |
| 0:20–1:10 | Dandália | Produtos: lista, busca, cadastrar (mostrar erro de validação), editar, excluir com confirmação | “Meu módulo é Produtos, com CRUD completo. Toda chamada passa por um service com Axios; o endereço da API Express fica no `.env`.” |
| 1:10–2:00 | Victoria | Estoque: status por cor + texto, filtro “só estoque baixo”, registrar entrada e ver a quantidade subir | “Fiz o design system a partir dos designs: cores, fontes grandes e componentes. No meu módulo, a entrada de mercadoria soma ao estoque.” |
| 2:00–2:50 | Jader | Login com Zustand; nova venda com 2 produtos, stepper travando no estoque, finalizar; detalhe da venda | “O login guarda a sessão no Zustand. Na venda, não dá para vender mais do que há em estoque, e a venda baixa o estoque automaticamente.” |
| 2:50–3:45 | José | Início com números, histórico com filtros, trocar para Modo Simplificado e aumentar o texto no “A A A” | “O Início resume o dia. No Histórico, entradas e vendas juntas. E o Modo Simplificado mostra só as ações principais com botões grandes.” |
| 3:45–4:00 | Todos | Tela Sobre | “Tecnologias: Expo Router, Zustand, Axios, TanStack Query e React Native Paper. Obrigado!” |

Dicas: gravar cada parte separada e juntar; usar o texto no tamanho “Grande”; começar sempre com o app recém-aberto (com a API conectada).
